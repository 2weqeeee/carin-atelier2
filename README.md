# Carin Atelier - Plataforma de Gestión

Este es el repositorio de la plataforma Carin Atelier, una aplicación web estática para la gestión de cursos, tienda y administración de alumnos.

## 🚀 Despliegue en Vercel

Esta aplicación está lista para ser desplegada como un sitio estático en Vercel.

### Pasos para desplegar:

1.  **Subir a GitHub**:
    *   Crea un nuevo repositorio en tu cuenta de GitHub.
    *   Sube todos los archivos de esta carpeta.
2.  **Conectar con Vercel**:
    *   Ve a [Vercel](https://vercel.com).
    *   Haz clic en "Add New" -> "Project".
    *   Importa tu repositorio de GitHub.
    *   Haz clic en **Deploy**.

## 🛠️ Tecnologías

-   **HTML5 / CSS3**: Estructura y diseño premium.
-   **JavaScript (Vanilla)**: Lógica de la aplicación y manejo de estado.
-   **LocalStorage**: Persistencia de datos local (Nota: Los datos son específicos de cada navegador/usuario).

## 📄 Estructura del Proyecto

-   `index.html`: Punto de entrada principal.
-   `app.js`: Lógica de la aplicación y controladores de vista.
-   `db.js`: Manejo de base de datos local y lógica de negocio.
-   `styles.css`: Estilos globales y sistema de diseño.
-   `products.json`: Base de datos inicial de productos.
